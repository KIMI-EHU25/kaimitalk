访问前自检三步

  1. 检查地址栏:确认浏览器地址栏显示的是 读取中… 且左侧出现 🔒 锁形图标。如果是 http://(没有 s)或图标变成红色感叹号，请立刻关闭页面。
  2. 检查证书:点击地址栏锁形图标 → 连接安全 / 证书有效。 证书签发机构应为 Cloudflare、Let's Encrypt 或类似可信机构,而不是 未知 / 未受信任 的中文名称。
  3. 检查内容:网页右下方应只看到 安全提示 这一个浮动按钮。如果 额外冒出弹窗广告、博彩链接、"安装加速器" 这类提示,基本可以判定为 DNS 劫持或运营商插入的广告 — 此网站本身从不投放任何广告。

如果看到弹窗或广告

  • 不要点击，立即关闭那些标签页。
  • 切换 DNS 到公共解析器: 1.1.1.1 · 8.8.8.8 · 223.5.5.5(阿里)。 切换方法见下方"如何切换 DNS"。
  • 条件允许时改用移动数据网络再访问一次。如果广告消失，基本可以确定是 家庭宽带运营商的 HTTP 注入。
  • 清除浏览器的此网站缓存(Ctrl+Shift+Delete → 仅 cookies + 缓存), 然后重新打开本站。
  • 如果短时间内反复出现可疑跳转，先停止使用并联系网站管理员。

如何切换 DNS(三大系统)

Windows 10 / 11
  1. 设置 → 网络和 Internet → Wi-Fi(或以太网)→ 你的连接 → 编辑 DNS 设置
  2. 选择 手动,IPv4 首选 1.1.1.1,备用 8.8.8.8
  3. 勾选 加密的 DNS over HTTPS → 保存
macOS
  1. 系统设置 → 网络 → 你的连接 → 详细信息 → DNS
  2. 把现有项目全部删掉，加入 1.1.1.1 和 8.8.8.8
  3. 确定 → 刷新 DNS:终端 sudo dscacheutil -flushcache
iOS / Android
  1. 系统设置 → Wi-Fi → 点击当前网络 → 配置 DNS / IP 设置
  2. 切换到 手动,输入 1.1.1.1 + 8.8.8.8
  3. 或下载 1.1.1.1 by Cloudflare 应用，一键启用全局加密 DNS
